This was my second uni project with the same group of two. Here we had to design an app for our stakeholder, mimicking a real world scenario. This app should allow the user to create their own simulation by importing their own environment and then add any number of agents with differents behaviours. This project also taught me how to optimise UI/UX due to the inherent need for user customisation.
